# Praktinis Darbas – Spring Boot + React (Vite) Projektas

Šis projektas susideda iš dviejų dalių:

- `praktinis_darbas` – **Backend** su Spring Boot (Java)
- `frontend` – **Frontend** su React ir Vite

## 💻 Reikalavimai

Prieš paleidžiant projektą, įsitikinkite, kad jūsų sistemoje įdiegta:

- **Java 17** ar naujesnė versija
- **Maven 3.8+**
- **Node.js 18+** ir **npm**

---

## 🚀 Projekto paleidimas

### 1. Backend paleidimas (Spring Boot)

```bash
cd praktinis_darbas
mvn spring-boot:run

```

## Po sėkmingo paleidimo backend serveris turėtų veikti adresu:

http://localhost:8080

### 2. Frontend paleidimas

```bash
cd frontend
npm install
npm run dev
```

Frontend aplikacija bus pasiekiama naršyklėje adresu:
http://localhost:5173
